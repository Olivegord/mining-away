# Public Roblox prompting patterns, including Opus 5.5

Researched October 27, 2026 for the owner's request to find well-known Roblox game prompts. These are source-backed patterns and a new project-specific prompt, not a claim that a viral prompt guarantees a polished game.

A [SandBase index of Belt's Roblox demo](https://www.sandbase.ai/lab/ai-videos/opus-5-5/2104871105752391780) reported 988 likes and 88.6K views for an Opus 5.5 one-prompt showcase. Those are third-party reported counts, not independently verified. The index says the exact prompt was not shared; the [original X post](https://x.com/bletDemonJH/status/2104871105752391780) returned 403 here. Treat this as a popular-looking demonstration claim, **not an available reproducible prompt**. [Ropilot's own site](https://ropilot.ai/) also advertises Opus 5.5 Roblox creation and playtest loops, but vendor demos do not establish a universal prompt or successful independent evaluation.

## What to put in this cloud task

The following wording is newly written for Mining Away. It combines the useful structure above with the owner's requirements, rather than copying anyone's prompt.

> Improve the existing Mining Away game in Olivegord/mining-away on codex/restore-feel-prestige. Read docs/OWNER_REQUIREMENTS.md first, then docs/ORIGINAL_FEEL_PARITY.md, docs/EXEMPLAR_RESEARCH.md and docs/VISUAL_QUALITY_GATE.md. Preserve original drones, crystals, their motion/mining feel, and the segmented pyramid turret. Build from assets/mining-away-base.rbxl to build/Mining Away.rbxl. Do not publish Roblox or create another experience.
>
> Make the player loop compelling with one starting permanent drone: mine, earn a pack, choose one of three server-generated cards, use that build to reach better guarded fields, then earn a prestige that adds one permanent drone. Persistent identity and fleet survive; run cards reset. Verify actual first-pack time, choices with distinct route benefits, and resistance to free-reprint attrition exploits. Keep results and pending offers server-owned and durable.
>
> Rebuild map presentation as a purposeful retro Roblox parts-built route inspired by Bee Swarm's readability, retaining this world's alien identity. Use coherent block construction, readable ground surfaces, grounded trees and meaningful landmarks. Preserve distinctive authored assets. Check every tree base against its supporting surface and inspect paths at player height; no floating props, accidental intersections, faceted low-poly terrain makeover or disconnected test platforms.
>
> Make the RNG UI small, interactive and tactile: one intentional pack opening, three readable cards, responsive hover/focus/press, clear target and exact benefit, deliberate selection, and a short acknowledgment after the server applies it. Keep the world visible. No giant debug boards, permanent card wall, repetitive rainbow gradients, emoji placeholder icons, fake near-miss roulette or long unavoidable rolling animation. Respect reduced motion and touch readability.
>
> Make beams and animation excellent in motion. Keep the original layered beam identity; connect the origin to the rendered emitter and the end to the current crystal surface. Inspect warmup, all three fracture stages, interruption, target death, recall and cleanup. Reject detached endpoints, stale beams, giant neon tubes, particles hiding the target, snappy drones, drifting grounded props and decorative animation unrelated to gameplay. Turret charge/fire/impact must read distinctly from mining. Test low and high graphics settings and representative fleet load.
>
> Spawn an independent visual quality reviewer with authority to reject the result. Tell it to be severe and specific: identify generic AI-looking composition, repeated filler, weak silhouettes, bad spacing, floating trees, awkward easing, cheap UI, sloppy beams and particle spam. It must examine real Studio captures/video and judge normal player views, full UI interaction and effects in motion. Code inspection, lint, passing unit tests and a flattering single screenshot cannot earn visual approval. Fix its concrete findings and obtain another review. Separately review behavior/parity, pacing and multiplayer correctness.
>
> Finish only with the reproducible build, exact commit, meaningful test results and an explicit independent visual verdict supported by captures. If Studio or another integration is unavailable, continue productive implementation and simulations, document the precise missing evidence, and leave visual/multiplayer approval pending. A progress summary is not completion, and an inaccessible renderer is not a visual pass.

## Specificity beats prompt hype

The strongest transferable pattern is to state the player action, visible response, original behavior to preserve, and evidence needed for acceptance. For a reviewer, “inspect 20 seconds of mining with multiple fleets and reject detaching beam endpoints or unreadable fracture cues” is actionable. “Make it amazing and not AI” alone gives too much room for a polished-sounding report about an uninspected result.
