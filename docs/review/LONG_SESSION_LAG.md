# Long-session lag investigation

November 1, 2026. The owner reports substantial lag after Studio has been open a long time and revokes repeated confirmations for routine stopping/installing/saving/restarting this game. AGENTS.md and the newest owner requirement record that preference. Publishing, new experiences and main merge remain outside scope.

Before the existing session closed, read-only native scene-analysis queries captured the long-running game. The four-second client sample contained 240 frames, with median 16.68 ms and 95th percentile 18.28 ms. That viewpoint/sample was near 60 FPS; it does not disprove intermittent lag during play or establish an improvement. SceneAnalysisService measured 176 total draw calls/62,454 triangles including shadows; only one particle draw call/132 particle triangles. The earlier inventory had 463 local presentation descendants and eight active particle emitters totaling about 31.5 particles per second. A pile of live visual objects was not evident in this snapshot.

Studio reported roughly 4.26 GB total memory and about 855 MB under its LuaHeap tag. SceneAnalysisService attributed about 2.57 MB to the client's game/core scripts and 1.39 MB to the server's game/core scripts; the main game controllers accounted for approximately 0.98 MB and 1.25 MB respectively. The client unparented query found fourteen objects, of which two were attributed to ClientDroneControl (a PlayerMouse and one Tween). The server query found none. These are single snapshots, not a time series proving absence of accumulation. Most reported memory is outside the scripts attributed by these queries; Studio/editor/plugin overhead is a possible direction for further profiling, not a confirmed root cause. Raw native query responses are preserved in LONG_SESSION_PROFILE.json.

Two unnecessary work paths were repaired without changing gameplay. Fully grown unchanged rocks now stop recomputing attributes, health colors, trigonometry and geometry each frame. Replicated changes mark their render record dirty, field-access/run changes invalidate visibility, and growth plus every queued black/shrink/break phase continues until settled. Orbital effects cache their visual descendants, update visibility only when active/stale/fading state changes, track new afterglow emitters and disconnect observation on destruction. They no longer build a descendant list and rewrite every effect each rendered frame.

The regression executes the actual production renderResource function against API doubles: 7,200 stable frames perform no additional source attribute reads; new health updates resume rendering, all black/shrink/break phases play once, and the final broken rock becomes dormant. Focused gadget/role/steering/collectible tests, all source/bundle compilation, economy/persistence checks and deterministic binary preservation pass. See LONG_SESSION_TEST_RESULTS.txt. This demonstrates removed work and retained behavior, not a measured long-session FPS/memory improvement.

The same project's saved native editable map receives only the allowlisted Source refresh. Opening that copy in Studio preserves the authored map and backup scripts; it is an artifact of Drone Blower revolution, not a new experience. Studio installation and follow-up sampling are recorded separately below when available. No publishing or main merge.
