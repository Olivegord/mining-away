# Context and objective reflow

Actual Studio TextService measurements on the earlier candidate showed 16px context copy requiring 32px within a 27px box at 320 and 390 viewport widths, and objective copy requiring 48px within 32px at 320. At a 430px safe width the 30px pack and prestige titles required 60px within a 43px box. These measurements are font-metric evidence, not final-build visual approval.

The revised layout widens and reflows context text, measures objective height, uses concise titles below a wider breakpoint, and expands the production Studio inspector to check Feedback, all three offer focus targets, onscreen bounds and text fit. The 41 pure geometry checks pass. The revised inspector has not been run against the final build, so native rendering and actual touch, focus and interaction remain unverified.
