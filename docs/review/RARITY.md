# Truthful server-defined rarity

New content-version 4 card choices carry `rarity = Common | Uncommon | Rare` in their saved resolved offer and selected card. All labels originate in the server catalog. The client may display that short label but must not invent a label for an older saved choice, expose the secret seed, display a fixed final probability, or imply that a rarer card is always strategically stronger. No Robux or paid reroll is introduced.

`Cards.weightedOrder` uses a deterministic weighted draw without replacement to place all currently useful/eligible candidate cards in an order: Common weight 6, Uncommon 3, Rare 1. The existing search then selects the highest-scored mutually compatible triple, prioritizing a combat/survival answer and an economy answer, an early signature option, category diversity and scope diversity. This order therefore only affects **ties** among equal-priority triples. Eligibility, present fleet/colors, stack caps and compatibility change the pool and scoring. The 6/3/1 values are **relative candidate-order weights**, not complete final card-appearance odds. A protected category can raise a tier's actual appearance frequency or leave only one eligible tier.

Server catalog allocation: Rare F09–F11 and D13–D20; Uncommon C01–C06, D09–D12, T01–T04; Common F01–F08, D01–D08, R01–R03. Scope/type/individual target, numeric effects, tradeoffs and this-run duration remain their own clear player-facing facts. Cosmetic differentiation should be restrained and readable without color alone; art style and reveal quality require final Roblox engine review.

## Executed checks

- The **actual production** weighted ordering was sampled on a controlled equal-priority fixture using 6,000 deterministic dispersed seeds. Common appeared first 3,597 times, Uncommon 1,816, Rare 587: a useful demonstration that candidate weights influence that fixture, **not an estimate of full-offer odds**.
- `tests/cards.spec.lua` checks version-4 saved rarity on all three options, no double charge on reopen or reconnect, exact frozen tier/target/selected effect after claim and retry, and a pre-tier version-3 paid offer surviving load/reopen/choice exactly with no fabricated rarity.
- `Profile.validate` accepts absent legacy tiers and the three known labels, but rejects unknown persisted rarity in either run cards or a paid offer. Migration fails closed without changing the stored input or fabricating a tier; `tests/profile.spec.lua` covers both paths.
- Existing seeded catalog, eligibility, no dominated options, three unique choices, early signature/economy/combat protection, stat caps, reprint/target, receipt eviction and prestige/stale-offer checks remain active. One fixed-seed controlled-preview fixture changed from its prior random seed because weighted candidate ordering intentionally changes offer order; it still exercises the same capped first drone and actual changed-drone preview.
- `tests/progression.spec.lua` still passes its six modeled checks over ten fixed non-cherry-picked seeds. With this v4 sampler, modeled first pack median 63.68s, first prestige 508.67s, second prestige 858.28s; the immediately prior model reported 63.68s / 458.43s / 810.55s. The approximate +11% first and +6% second prestige changes are directional warnings from a small heuristic simulation, not actual player outcomes or a reliable estimate of release balance. First-pack cost is unchanged. Retune only after actual Studio playtime/choices and consider offer-weight fairness independently.
- Extended the same deterministic model to seeds 1–100 by temporarily replacing its seed loops, without changing its mechanics: all 100 reached both prestiges within the model time limit. First prestige median 486.30s (range 382.71–587.14), second median 850.60s (range 738.08–1077.98). This is still a model, not live playtesting; no comparable 100-seed baseline was measured.

Visual appearance, feel, actual full-offer frequencies, real persistence service behavior and two-client Roblox behavior remain unverified here. Record real final-revision footage and the independent visual review verdict separately.
