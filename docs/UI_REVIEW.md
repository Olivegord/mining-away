# Client presentation review

This is a source/layout review, not a Roblox Studio visual or multiplayer playtest. The cloud has no Roblox renderer. Original-versus-repaired video, actual mesh pivots, bloom, text rendering, native touch prompts and two-client smoothness remain Studio acceptance items.

## What changed

The always-visible HUD is at most 310 × 102 pixels (clamped to viewport width minus 36), with credits, cargo fill and permanent fleet count. A single objective sits beneath it; the rest of the screen remains the world. Recall is one compact lower-right button. Evade appears only while a local crew is attacking. A single nearby sentry health/charge strip replaces per-turret billboard spam.

Pack and prestige interactions live at their physical depot stations. Native ProximityPrompt touch/keyboard activation and the compact contextual Use button share a small debounce. The original Converter is queried in its existing Workspace location rather than assuming it moved under the new map folder. Card choices appear only for a saved pending offer or an explicit machine interaction. Closing that screen does not ask the server to reroll. The selected button says Saving until authoritative profile feedback arrives.

Desktop choices use three 248-pixel-high cards with separate title, exact target, precise effect, actual before/after preview, This Run tag and selection button. Below a 720-pixel viewport width, cards stack in a scrolling region. HUD, context and notice widths clamp for small screens, with context lifted clear of recall controls and notices moved below the HUD. Width follows viewport size when opened; typography stays fixed and readable instead of shrinking the entire UI. Device rotation while a modal is open is a pending engine usability check; reopening recomputes layout.

Prestige displays the actual existing and resulting permanent fleet, next drone type, number of run cards, credits and cargo being reset, and the server's eligibility result. Confirmation is disabled until eligible and no paid pending choice remains. It never sends an ordinary sell action as prestige. Fleet inspection uses server-computed effective stats when provided; permanent IDs/types remain visible.

## Movement and effects review

All observers use independent local drone viewmodels cloned from the complete original ReplicatedStorage.Drone template, not partially replicated authoritative models. The loader waits for the original Mesh body, Emmiter, Attachment, WeldConstraint and both beam layers, then retries once per deferred replication batch. The original Drone has no SpecialMesh; its actual body and visible emitter are retained, with the emitter and a restrained 25% body tint receiving the type accent. The tint is necessary because read-only geometry inspection found the smaller emitter enclosed by the body; shape and material are unchanged. Authoritative models are hidden only with local transparency; server position/goal/state, reservations and combat remain untouched. The rendered flight applies the shared original `.03` eased/capped approach at render frequency and horizontal yaw with one `.1` elapsed-time blend. Following can reconstruct the radius-10, +7-height formation from the owner's visible character. Server correction uses a drift deadband, not the rejected double low-pass pose chain. Teleports/life transitions reset the local pose.

Crystal views clone the original union. Server spawn/ready timestamps reconstruct the two-second Quad.Out rise and growth for late arrivals. Server stages reshape the visible mesh to 75%, 50% and 25% with stable seeded tilt. A bounded cosmetic queue holds every newly crossed quarter for at least 0.09 seconds before the final hide/shatter, so 10 Hz snapshots or fast cards cannot skip the visible 25% stage. Damage, rewards and server timing do not wait for this queue. A break implies all quarters crossed even if replication delivers its attribute first. Original RockCrack/RockBreak sounds are cloned only if present in the supplied place; no guessed external asset is substituted if the historical snapshot lacks them. Existing stage/break serials initialize silently on late join, so old cracks/payouts do not replay. The beam endpoint follows the current visible top surface.

The original MiningFX beam template is reused when available, with a two-second show envelope and 0.2-second hide. Beam attachments belong to rendered emitters and local world-space endpoints. Drift correction cannot authorize mining. Turret charge rays use the server-frozen Aim; both original eye and overlaid spawnEye receive the charge/fire accent. A late join initializes ShotSerial rather than replaying old shots. Local chips cap at 48 concurrent parts; no point lights are added.

## Executed checks and findings fixed

- Client compiled with official Luau 0.744 after the final template/mobile corrections. Mathematical rectangle checks at 320, 360, 720 and 1366 pixel widths keep HUD/context/notice bounds inside the viewport; these are layout calculations, not engine text-rendering tests.
- Standalone Luau analyzer passed with Roblox host globals explicitly typed `any`; this is syntax/lint coverage, not Roblox API type validation.
- Static review caught and fixed: field-parented resources missed by a Resources-folder-only observer; turret `Turret=true` versus assumed TurretId; externally retained Converter missed by station search; double yaw easing; original spawnEye visually obscuring eye-only telegraphs; wrong case for Player card scope; missing exact prestige reset amounts; fleet stat wrapping; delayed replicated geometry/attributes; original GUIs reappearing on respawn; template descendants arriving after an authoritative model; and fixed HUD/context/notice widths overflowing a 320-pixel viewport.
- Independent geometry/feel agent reviewed the renderer contract and these corrections.

## Remaining Studio checks

Compare 30/60/144 FPS flight and close mining approach with the original camera/scale; verify no snapshot-driven vibration, downward body pitch or sideways station offset. Check original emitter pivot, downward beam tip, grow-in and all three quarter stages on ordinary rocks and geodes. Confirm three choices scroll/read/select on desktop and touch, native prompts work once, portrait HUD fits, and prestige text remains readable with larger fleets. Join during growth, mining, a turret charge and free reprint from another client. Verify old effects do not replay and every observer sees the same state. No such engine result is claimed here.
