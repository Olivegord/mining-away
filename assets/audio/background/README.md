# DRONEREVOLUTION soundtrack

Each track is reserved for one activity. Credits and upload IDs are recorded
in [tracks.json](tracks.json).

| Activity | Track |
| --- | --- |
| Amber | Ambient · Leberch |
| Ruby | Matt’s Emotional Ambient Synthscape · mattc90 |
| Quartz | Calm Ambient Dreamscape · Morgan |
| Violet | Sci-Fi Ambient · AtlasAudio |
| Diamond | Deep Ambient · AvelineMusic |
| Repeated backpack sales | Chill Ambient · VelarioMusic |

The soundtrack is on by default and uses the existing Music toggle. It starts
with 55–95 seconds of silence. After a song ends, there are 150–300 seconds
of silence. The player must be inside the corresponding Crystal Run bed while
their crew works that field for a randomly selected 75–120 seconds. Pauses of
up to 12 seconds keep the progress without adding mining time.

Three separate paid backpack sales within five minutes make the sell-route
track eligible for 55 seconds. A paid backpack sale is the confirmed server
receipt used by the existing sell animation. Courier receipts cannot count
toward this streak. The existing music group ducks during combat and menus.
A song already playing finishes across changes of field or activity.

The five MP3s were uploaded as supplied. The 25 MB Ruby WAV was resampled to
32 kHz stereo PCM with macOS `afconvert -f WAVE -d LEI16@32000`, preserving the
full 141.6 seconds under the 20 MB upload limit. The source recordings remain
local. The game uses the six uploaded Roblox audio assets.
